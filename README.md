# Заготовка для проекта интернет-магазина

## Описание:

Данный проект не представляет ныне какого-либо интереса и не преследует коммерческие цели. Он создан для оттачивания навыков работы и оформления кода для молодых и неопытных будущих специалистов.

Проект моделирует работу магазина: товары, категории, цена и количество на складе, а также отдельные типы товаров (смартфоны и газонная трава).

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/alb-xab/mark_prj.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте папку с файлами. Основные классы и функции находятся в папке `src`.
2. Для проверки работы запустите пример:
```
python -m src.main
```
либо создайте объекты в своём скрипте и выведите результат через `print`.
Пример:
```
from src.classes import Product, Category

product = Product("Iphone 15", "512GB", 210000.0, 8)
print(product)
```
3. Увиденные результаты оцените по шкале от 1 до 10 и оставьте свой отзыв, или свяжитесь с разработчиком, чтобы передать ему свои советы, пожелания или угрозы в расправе, чтобы он стал лучше работать.
4. Спасибо за внимание!

## Информация о модулях.

classes — основные классы проекта:
- `Product` — товар (название, описание, цена, количество), строковое представление, сложение стоимости на складе, создание из словаря, геттер и сеттер цены;
- `Smartphone` — наследник `Product` по категории "Смартфоны" (производительность, модель, память, цвет);
- `LawnGrass` — наследник `Product` по категории "Трава газонная"(страна-производитель, срок прорастания, цвет);
- `Category` — категория товаров (приватный список товаров, добавление продукта, вывод списка, счётчики).

utils — вспомогательные функции: чтение данных из JSON, создание объектов категорий и товаров, итератор `CategoryIterator` для перебора товаров категории.

main — пример запуска и демонстрации работы классов.

## Тестирование

1. Откройте папку с файлами тестирования. Файлы находятся в папке `tests`.
2. Для теста функций вызывайте каждую по отдельности, либо же все вместе с помощью pytest:
```
pytest -v
```
3. Результаты покрытия тестами вы можете найти в папке `htmlcov`.
4. Спасибо за внимание!
